Data boundaries

The useful disclaimer is part of the product story.

Instead of promising identical results in every pool, we show the practical boundaries that should be resolved before a final recommendation.

“A catalog value becomes meaningful only when its model and test condition travel with it.”

Performance review principle for technical quotations
Why the listed COP is not a yearly operating-cost promise

COP is a ratio at a stated point. Air temperature, humidity, water temperature, flow and part-load control can change it. Compare values only where the conditions and definitions match.

Why a dB(A) figure is not a site-noise guarantee

The product table lists a noise value, but the measurement distance and operating mode are not stated. Local geometry, reflections, mode and placement also affect the installation result.

Why water connection size cannot replace a flow check

Main grades list a 1.97-inch water connection, yet the required flow is grade-specific. Pump performance, filtration, pipe resistance and bypass arrangement all need review.

Why refrigerant and compliance need a final-market check

The product data list R32 and GWP 675 for the range. Market legality, final charge, labeling, handling and servicing obligations must be confirmed for the final model and destination.

Channel focus

Different partners need different first answers.

The inquiry route changes the technical and commercial questions that matter. A distributor's stock plan, a builder's site fit and an installer's start-up path should not be treated as the same conversation.

01 / DISTRIBUTION

Line review with fewer blind spots.

02 / BUILD & REMODEL

Specify around the site, not the brochure.

Use pool volume, cover use, target temperature, pad layout, neighbours and power supply to shape the first recommendation.

03 / INSTALL & SERVICE

Make startup evidence part of the handover.

Verify flow, filtration, wiring, drainage and the safe shutdown response before a project turns into a return visit.
